# Kampfbilder

Ego-Perspektive, Stein-Gang, Fackeln. Zwei Gegner, dieselben Ausgänge.

- `pixel-gifs/` Seitenansicht, eine GIF pro Runde
- `ego-gifs/` dieselbe Folge in Ego-Pixel
- `hd/brecher/` 13 Platten, Brecher
- `hd/jaeger/` 14 Platten, Jäger, Schuss extra
- `hd/jaeger-film/` ein Film und die Schnitte daraus
- `hd/platten/` frühere Schlüsselplatten
- `hud/` übernehmbares Kampffenster, `KampfHud.set(zustand)`, plus Film mit HUD
